# f2recombination_rate

## 功能

从逐 SNP 祖源追溯结果识别父本和母本的相邻祖源转换，按指定窗口统计重组事件数。使用用户指定的群体人数计算父本、母本及合并重组率。

本命令替代旧的 `recomb_calcul`。输入为 `f2trace_haplotype` 输出经 `concat_parquet` 合并的结果，不使用已过滤窗口内祖源转换的 `f2window_divided` 输出。

## 输入

Parquet 文件必须包含以下字段。每个个体、每条染色体、每个 SNP 位置只能有一行。

| 字段 | 含义 |
| --- | --- |
| `F2_ID` | F2 个体编号 |
| `CHR` | 整数染色体编号 |
| `POS` | 从 1 开始的整数 SNP 坐标 |
| `PAT_HAP` | 父源拷贝祖源编码，5 或 6 |
| `MAT_HAP` | 母源拷贝祖源编码，11 或 12 |

程序按染色体分批读取，仅选择上述五列，并在同一个体内按 SNP 坐标排序。输入中出现的所有染色体都会被处理，不自动排除任何染色体。本文分析应输入常染色体结果。

## 参数

| 参数 | 必需 | 含义 |
| --- | --- | --- |
| `-i, --input` | 是 | 输入 Parquet 文件，另兼容 `--input_file` |
| `-o, --output` | 是 | 输出 Parquet 文件路径，另兼容 `--output_file` |
| `-c, --count` | 是 | 指定群体人数，必须为正整数，没有默认值 |
| `--window_size` | 否 | 窗口大小，单位 bp，默认 1000000，必须为正整数 |

## 示例

```shell
statstools f2recombination_rate \
  -i f2inheritance.parquet \
  -o recombination_100kb.parquet \
  --count 578 \
  --window_size 100000
```

设置 `--window_size 10000` 使用 10-kb 窗口。设置 `--window_size 1000000` 使用 1-Mb 窗口。

## 事件计数和窗口归属

先在同一个体、同一染色体内比较相邻 SNP，再进行窗口汇总。父本 5 与 6 之间的转换计一个父本事件。母本 11 与 12 之间的转换计一个母本事件。不同个体或不同染色体之间不进行比较。

转换事件归入前一个 SNP 所在的窗口，只计一次。窗口编号使用 `POS // window_size`，与 `f2window_divided` 一致。例如，窗口大小为 100000 时，坐标 99999 属于窗口 0，坐标 100000 属于窗口 1。二者之间的转换计入窗口 0。这是左侧标记归属规则，不表示真实断点就在该 SNP 上。

空窗口也保留。输出从窗口 0 连续延伸到该染色体最后一个 SNP 所在的窗口，不推测最后一个 SNP 之后的染色体长度。`snp_count` 统计不同 SNP 位置数，同一个位置在多个个体中出现只计一次。

没有 SNP 的窗口，事件数和重组率均输出 0。这个 0 只表示没有归属到该窗口的已检测事件，不能证明该区域不存在重组。很小的窗口不意味着获得了同等精度的断点定位。

## 分母和重组率

设指定人数为 N，窗口内父本事件数为 Cp，母本事件数为 Cm。

| 结果 | 公式 |
| --- | --- |
| `p_rate` | Cp / N |
| `m_rate` | Cm / N |
| `total_rate` | (Cp + Cm) / (2N) |

结果为原始比值，不乘以 100，不进行舍入。它表示每次指定传递在该窗口内检测到的平均事件数，不是重组个体比例，也不是 cM/Mb。同一条传递染色体在一个窗口内可以贡献多次事件，结果不截断到 1。

`count` 始终决定分母。实际个体数与指定人数不一致时，只记录警告，计算继续。祖源缺失或异常编码同样记录警告，只统计两端祖源都有效的相邻比较，不跨过缺失记录连接更远的 SNP。母本缺失不影响父本有效记录的比较，反之亦然。这些情况都不会改变指定分母，也不会补回未知事件。

## 输出字段

每行对应一个染色体窗口，按 `chra` 和 `windowa` 排序。

| 字段 | 含义 |
| --- | --- |
| `chra` | 染色体编号 |
| `windowa` | 窗口编号，从 0 开始 |
| `window_size` | 用户指定的窗口大小，单位 bp |
| `snp_count` | 窗口内不同 SNP 位置数 |
| `p_count` | 父本重组事件数 |
| `m_count` | 母本重组事件数 |
| `total_count` | 父本与母本事件数之和 |
| `p_transmissions` | 用户指定的 N |
| `m_transmissions` | 用户指定的 N |
| `total_transmissions` | 用户指定的 2N |
| `p_rate` | 父本窗口重组率 |
| `m_rate` | 母本窗口重组率 |
| `total_rate` | 合并窗口重组率 |

同名输出文件会被覆盖，输出路径不能与输入相同。日志同时输出到终端和结果文件所在目录。日志包含参数、各染色体实际个体数、父本和母本祖源缺失及异常记录数、至少有一个有效祖源记录的个体数、窗口数和事件数。日志中的个体数仅用于报告，不替换指定分母。

人数不匹配不会停止运行。无法解释的文件结构问题，例如缺少必要字段、缺失坐标或重复的个体与 SNP 位置，仍会报错，避免产生无法定义的相邻比较。
